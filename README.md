
# 🌟 Depiclub - Sistema de Gestión de Estética

Sistema integral diseñado para la gestión profesional de centros de estética, especializado en depilación con cera, láser y tratamientos de gabinete.

## 🚀 Características Principales

- **Gestión de Cera**: Registro por número de ticket, control de zonas y cálculo automático de comisiones por depiladora.
- **Módulo de Láser**: Agenda por jornadas, seguimiento de sesiones por zona (S#1, S#2...) y base de clientas vinculada.
- **Estética y Combos**: Venta de packs de sesiones, gestión de pagos parciales y control de deudas de clientas.
- **Finanzas**: Libro de gastos por categorías y balance de caja (Efectivo vs Mercado Pago).
- **Inteligencia Artificial**: Integración con Google Gemini para análisis de estrategia de negocio y crecimiento.
- **WhatsApp**: Envío de recordatorios, recupero de ausentes y promociones mediante API Cloud o enlaces directos.

## 🛠️ Tecnologías

- **React 19** + **TypeScript**
- **Vite** (Build tool)
- **Tailwind CSS** (Diseño moderno y responsive)
- **GitHub Actions** (Despliegue automático a GitHub Pages)
- **Gemini API** (Inteligencia de negocios)

## 🔐 Seguridad

El sistema cuenta con un **Modo Maestro** protegido por PIN.
- **PIN por defecto**: `1234`
- El PIN puede ser modificado desde la pestaña **WhatsApp / Configuración**.

## 📦 Instalación Local

Si deseas ejecutarlo en tu computadora:

1. Clona el repositorio.
2. Ejecuta `npm install` para instalar dependencias.
3. Ejecuta `npm run dev` para iniciar el servidor de desarrollo.
